## 🚀 Featured Projects

### 🔗 [Web URL RAG Chatbot](https://github.com/abhijeet8390)
`LangChain` `FAISS` `Docker` `AWS`
- Built and deployed a RAG chatbot to query any webpage in natural language, using local HuggingFace embeddings.
- Context-grounded prompting pipeline with source citations, conversational memory, and hallucination-reduction constraints.
- Containerized with Docker and deployed on AWS (ECR + App Runner) for public API access.

### 🛡️ Network Intrusion Detection System
`Random Forest` `Streamlit` · **Macro F1: 96%**
- Built on RT-IoT2022 (123k records, 12 attack classes); handled 77% class imbalance with `class_weight='balanced'`.
- Deployed as a real-time Streamlit app for live IoT network attack detection.

### ✍️ Handwritten Alphabet Recognition (A–Z)
`CNN` `RNN` `Random Forest`
- Compared Random Forest and CNN on 372,450+ handwritten alphabet images (28×28px); CNN reached 97% validation accuracy.
- Full pipeline: EDA, pixel normalization, model training, and prediction visualization.
